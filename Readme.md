# AI Assignment 1 - BFS and DLS

## Overview
This assignment demonstrates the implementation of two uninformed search algorithms:

- Breadth First Search (BFS)
- Depth Limited Search (DLS)

These algorithms are commonly used in Artificial Intelligence for graph traversal and path finding.

## Objectives
- Understand graph traversal techniques.
- Implement BFS using a queue.
- Implement DLS using recursive depth-limited search.
- Compare the behavior of both algorithms.

## Technologies Used
- Python 3
- Jupyter Notebook

## Files
- bfs_dls.ipynb – Complete implementation
- requirements.txt – Required libraries

## How to Run

1. Clone the repository
2. Open Jupyter Notebook
3. Open `bfs_dls.ipynb`
4. Run all cells

## Learning Outcomes
- Graph representation
- Queue operations
- Recursive search
- Depth limiting
- AI search techniques
